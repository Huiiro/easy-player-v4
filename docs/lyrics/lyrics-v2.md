# 歌词组件 v2

播放器入口已改为 `PlayerLyricsV2.vue`，旧版 `PlayerLyrics.vue` 保留。其他调用方只需更换 import，props、默认值、根节点 class/style 透传及 `seek(positionMs)` 事件保持一致。时间单位仍为毫秒。

## 滚动实现

参考 [AMLL 歌词组件](https://github.com/amll-dev/applemusic-like-lyrics/tree/main/packages/core/src/lyric-player) 的布局目标、独立位置弹簧和用户滚动接管思路；本地实现不引入 AMLL 依赖。

- 原生滚动位置采用频率参数 9 的临界阻尼弹簧，每行采用频率参数 10～6.5、阻尼比 0.82 的独立弹簧，带轻微回弹。后续行逐行延迟 60ms（最大 260ms），重新指定目标时保留速度，动画结束后停止 RAF。自身滚动事件不会再中断弹簧。
- 高亮行中心停靠在歌词视口顶部 1/4 处，上下留白分别为视口的 25% 和 75%，确保首尾行也能到达该位置。纯文本歌词仍使用对称留白。
- 行位移直接更新 CSS 变量，缩放单独过渡，避免 CSS transform 过渡再次拖慢位置弹簧。
- 滚轮、触摸和键盘滚动立即接管，静止 1.5 秒后回到当前行。普通无时间戳歌词保持自由滚动。
- ResizeObserver 观察容器和歌词轨道；字体、翻译、罗马音、对齐与布局入口改变后重新定位。
- `reduceMotion` 或 `allowTransform=false` 时直接定位，关闭行与逐字位移。暂停且布局稳定时没有持续动画循环。
- 扫字用 RAF 覆盖实际时间样本间隔插值（最长 500ms），只更新当前行正在变化字符的单个 CSS 变量。字符时间缓存，已完成和未开始字符不重复写入；保留原有双层渐变扫字、透明度渐亮、上浮和缩放，通过同一进度变量驱动，不叠加 CSS 过渡。暂停后最多追到最后一个确认时间，不继续预测；大幅跳转和倒退立即同步。
- 歌曲和来源监听分别比较字段值，父组件传入内容相同的新数组或对象时不重载歌词，避免播放进度更新反复重置扫字。
- 保留 LRC 的时间戳空白行，以三个点表示间奏，随进度依次点亮、轻微呼吸并在下一句前 400ms 淡出；暂停时停止推进。超过 3 秒的前奏与明确 endMs 到下一句之间的空档也显示省略号。普通 LRC 的长句和纯文本不猜测间奏；只有时间戳而没有歌词的文件仍按空来源处理。

歌词解析、来源优先级、强制来源、网络搜索、重载、翻译、罗马音/ruby、逐字填充、普通歌词样式、颜色变量和自动字号入口沿用现有实现。

## 验证

独立浏览器测试页：运行 `node scripts/lyrics-v2-preview.mjs`，访问 `http://127.0.0.1:5197`。它只替换 UI store 和歌词数据接口，挂载实际 v2 组件及现有歌词解析器，不读取或修改音乐库。

测试页使用播放页的 Grid/Flex 嵌套，并从播放页读取布局 CSS，歌词组件不再单独设置固定像素高度。回归验证：外层高度 560px、歌词区域 496px、滚动视口 432px，长歌词只增加内部 scrollHeight；跳转及翻译切换后外层高度不变。

修复过的布局问题：普通流歌词轨道撑高 Grid 的自动最小行高，动态上下留白又随视口高度增长，造成 ResizeObserver 持续扩张，封面和歌词都被外层裁剪。轨道现采用绝对定位，Grid 行使用 `minmax(0, 1fr)`，歌词区域和视口允许收缩到内容高度以下。

已验证：中段跳转居中（误差 < 1px）、翻译切换重排、减弱动画、点击 seek 的毫秒值、键盘滚动接管及恢复、纯文本展示。弹簧验证了 30/60/144 FPS 收敛与反向改目标。

运行 `node scripts/test-lyrics-motion.mjs` 检查弹簧回弹、不同帧率收敛、扫字插值、暂停与前后跳转。测试页提供 Play/Pause、Timed lyrics（YRC）及 Measure motion：以 100ms 进度样本进行 1.4 秒采样，普通歌词测得 85 帧、39 种填充状态、最大行间位移差约 94px；YRC 测得 85 帧、40 种填充状态、位移差约 50px。计数随浏览器调度变化，不代表真实音频播放的性能基准。

新增组件和弹簧文件通过 ESLint；`typecheck:web` 未报告新增文件错误，但全项目仍有旧组件、playerStore、下载页等既有类型错误。尚未进行真实音频播放及超长歌词性能测试。

后续 250ms 低频输入回归：修复重复加载后，每次采样间隔可记录约 13～16 种扫字填充值（此前只有 2～3 种）。测试页 Interlude lyrics / Inside break / After break 已验证前奏、空白段三点显示与下一句恢复；单元测试覆盖时间戳空行保留和明确间奏插入。历史 100ms 记录仅作此前版本对照。

样式回归修复：移除伪元素覆盖层，恢复原逐字外观；行切换与扫字使用同一插值时钟，避免句尾提前消失。使用 v-memo 缓存未变化歌词行。250ms 输入下，稳定采样段记录 14～15 次填充变化；浏览器计算样式验证填充背景、0.25～1 透明度及浮起缩放均生效。这是独立组件测试结果，不能代替真实播放页 GPU 性能分析。
