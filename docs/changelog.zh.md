# Easy Player 更新日志

[English](changelog.en.md)

本文档按版本从新到旧记录功能更新、体验改进与问题修复。

## v3.4.0

- 新增应用内更新检查、下载和重启安装，支持启动时自动检查、更新提醒及忽略指定版本，并可关闭自动检查。
- 新增设置搜索，可按设置名称、描述和关键词定位到对应分组。
- 新增曲库文件夹监听，自动导入目录及子目录中的新歌曲，启动时补充检查；支持管理监听目录及导入提醒，并修复文件删除后的重复导入问题。
- 支持拖入本地音频文件或文件夹导入曲库；完善失效歌曲清理，并可选择新音乐目录重新匹配移动后的文件。
- 新增重复歌曲检测，支持文件哈希、元数据快速检查及本地音频指纹深度比对，提供进度、分析缓存和清理前确认；相似音频作为待复核候选，不自动删除文件。
- 新增 Windows 系统媒体控制集成，显示歌曲信息与封面，支持系统播放控制；完善任务栏播控条、缩略图按钮及封面更新。
- 新增网络代理模式，支持关闭、跟随系统或自定义 HTTP、HTTPS、SOCKS5 代理，用于插件宿主网络请求、插件安装及宿主媒体解析与下载；配置重启后保留。
- 新增内置 Liquid Glass 样式开关，可叠加主题配色、自定义图片和视频，统一侧栏、底栏、弹窗、菜单及控件材质；改进实时折射、滚动表现与资源释放，并扩展主题插件的玻璃样式变量。
- 新增播放器粒子流动背景，优化网格背景、环境光取色、封面样式与背景切换，减少页面隐藏及减少动态效果时的动画开销。
- 完善 Auto Mix 可选人声分离组件的安装、状态检查与缓存管理，改进跨格式过渡；非 1 倍速播放时暂停交叉淡化与自动混音，恢复原速后重新启用。
- 修复 YRC 逐字歌词解析及歌词波浪动画，完善歌词缩放、偏移调节与桌面歌词设置体验。
- 优化播放器、底栏及更多菜单的布局和交互，统一弹窗样式并修复关闭后的资源清理，改进搜索浮层、页面滚动与设置布局。
- 修复歌单默认排序及多选操作，改善列表加载、页面切换和播放期间的性能表现。
- 完善 Windows 与 macOS ARM64 构建和运行依赖打包，固定并校验媒体解析及音频指纹工具，支持按需下载 Auto Mix 组件。

## v3.3.1

- 新增任务栏右侧常驻播控条，显示歌曲名和歌手，支持上一首、播放/暂停和下一首，可在系统设置中开关。

## v3.3.0

- 新增插件管理页，支持从官方索引按需安装、更新、启用、停用及卸载来源和主题插件，并可查看、筛选、导出和清空插件日志；应用启动时不自动下载插件。
- 将网易云音乐、酷狗、QQ 音乐的歌词、封面和元数据，以及哔哩哔哩、YouTube 的媒体搜索与下载迁移至独立官方插件，提供公共插件 SDK。
- 将黑洞、雨夜、极光、海洋、日落、森林、矩阵、星空、星轨及 DNA 背景迁移为可独立安装的主题插件；支持本地导入第三方数据与 shader 主题包，官方代码背景在沙箱框架中运行。
- 新增 WebDAV、SMB、FTP、显式与隐式 FTPS、SFTP 远程文件源，并扩展 Subsonic 支持；统一连接配置、认证方式、凭据加密存储和 SFTP 主机指纹校验，提供远程歌曲缓存。
- 新增歌曲元数据来源搜索与预览，可选择字段、封面和歌词写入本地文件；支持重新读取文件标签，并通过版本校验避免覆盖过期编辑，限制修改正在播放的文件。
- 完善歌词管理，新增歌词编辑器，支持时间轴编辑、原文/翻译/罗马音处理、格式转换、导入导出和保存；支持为单曲设置歌词偏移及批量标记纯音乐、禁用网络歌词。
- 新增 Auto Mix 自动混音，分析节拍、调性及首尾静音以调整交叉淡化，支持不同 PCM 采样率、声道数与位深之间的连续过渡；可选本地人声分离运行时提供人声保护和临近人声切入，未配置时回退至普通自动混音。
- 新增紧凑播放器布局，优化播放器封面、歌词、底栏与音频控制面板，支持底栏自动隐藏和滑动交互，并调整窄窗口布局与页面切换动画。
- 扩展 Windows 窗口材质设置，支持云母与亚克力，统一主题配色、背景切换和自定义主题资源的显示行为。
- 优化全局搜索与来源搜索、专辑浏览、歌曲列表排序及列布局，改进歌单标题、卡片动效、侧边栏封面和菜单定位。
- 支持批量设置歌曲偏好及清空减少推荐记录，优化推荐反馈与曲风分隔符处理。
- 修复播放队列清空后仍恢复旧曲目、队列刷新影响导航状态及异步切歌状态覆盖等问题；改进窗口就绪显示、桌面歌词层级、下载音频封装与临时文件路径处理。

## v3.2.2

- 新增自定义主题，支持 JSON 与 ZIP 资源包的导入、切换、导出、同名替换和删除。
- 新增主题资源清单，可为指定区域分配图片、字体和文字，支持图片进度滑块及随包携带字体许可文件。
- 新增第三方主题风险提示；导入时提供 10 秒预览，确认后保存，取消、按 Esc 或超时恢复原主题。已安装主题和默认外观的后续切换立即生效。
- 自定义主题默认接管主界面背景，也可保留原背景；修复主题欢迎语覆盖用户自定义欢迎语的问题。
- 统一全局控件样式，开放侧边栏、按钮、输入、进度条、对话框、抽屉及菜单等组件的主题变量与公共类。
- 修复透明或半透明的未播放轨道透出主色、导致整条播放进度颜色一致的问题。
- 新增底栏布局设置，支持居中进度和顶部进度线、最大宽度与进度区域占比；窄窗口自动调整布局并将溢出操作收进更多菜单。
- 新增推荐歌单独立详情页，点击首页歌单名称可查看对应日期的完整歌曲，支持播放全部、搜索、排序及歌曲操作；点击封面保留播放行为。
- 普通歌单与推荐歌单分别记忆标题的收起或展开状态，切换页面和重启后保留。
- 首页快捷导航新增喜欢的歌曲与推荐入口，统一统计时段、音质和其他概览卡片的图标悬停动效。
- 播放器倍速前新增歌曲偏好按钮，依次切换中立、喜欢和不喜欢，以空心心形、实心心形和向下手势展示；放大手势图标时保持按钮尺寸不变。
- 新增统计开关和清空统计数据功能，关闭统计后停止记录并隐藏相关统计、历史和推荐内容。
- 新增恢复默认设置功能，可重置界面、播放器、快捷键等偏好，保留曲库文件及播放统计。
- 本地文件夹右键菜单新增播放歌曲和加入歌单操作。
- 补充主题开发规范、变量默认值与作用范围、资源包清单及字体使用说明，并提供可导入示例。

## v3.2.1

- 新增可配置的快进与回退 5 秒、收藏歌曲、减少推荐和桌面歌词快捷键，支持应用内和全局绑定。
- 新增开启轻量模式的快捷键，默认使用 Ctrl+E，退出轻量模式仍需手动操作。
- 修复模式状态与实际窗口不同步时轻量模式快捷键失效的问题，并修复界面设置未正确保存到数据库的问题。
- 新增资料库单曲导入，支持选择本地音频文件加入资料库。
- 将文件夹导入入口统一命名为“导入文件夹”。
- 新增“忽略 5 秒以下的歌曲”开关，默认开启；文件夹和单曲导入均按此设置过滤短音频，并提示忽略数量。
- 将音频控制入口从底部栏移至顶部栏。
- 新增自动生成的构建号，可在设置中查看。
- 新增应用内更新日志，支持离线查看，并随界面语言显示中文或英文内容。
- 优化曲库搜索，支持拼音、罗马音与相关度排序，并改进中文、英文和日文混合名称排序。
