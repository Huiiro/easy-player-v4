# Easy Player 更新日志

[English](changelog.en.md)

本文档按版本从新到旧记录功能更新、体验改进与问题修复。

## v3.2.2

- 新增自定义主题，支持 JSON 与 ZIP 资源包的导入、切换、导出、同名替换和删除。
- 新增主题资源清单，可为指定区域分配图片、字体和文字，支持图片进度滑块及随包携带字体许可文件。
- 新增第三方主题风险提示；导入时提供 10 秒预览，确认后保存，取消、按 Esc 或超时恢复原主题。已安装主题和默认外观的后续切换立即生效。
- 自定义主题默认接管主界面背景，也可保留原背景；修复主题欢迎语覆盖用户自定义欢迎语的问题。
- 统一全局控件样式，开放侧边栏、按钮、输入、进度条、对话框、抽屉及菜单等组件的主题变量与公共类。
- 修复透明或半透明的未播放轨道透出主色、导致整条播放进度颜色一致的问题。
- 新增底栏布局设置，支持居中进度和顶部进度线、最大宽度与进度区域占比；窄窗口自动调整布局并将溢出操作收进更多菜单。
- 新增推荐歌单独立详情页，点击首页歌单名称可查看对应日期的完整歌曲，支持播放全部、搜索、排序及歌曲操作；点击封面保留播放行为。
- 普通歌单与推荐歌单分别记忆标题的收起或展开状态，切换页面和重启后保留。
- 首页快捷导航新增喜欢的歌曲与推荐入口，统一统计时段、音质和其他概览卡片的图标悬停动效。
- 播放器倍速前新增歌曲偏好按钮，依次切换中立、喜欢和不喜欢，以空心心形、实心心形和向下手势展示；放大手势图标时保持按钮尺寸不变。
- 新增统计开关和清空统计数据功能，关闭统计后停止记录并隐藏相关统计、历史和推荐内容。
- 新增恢复默认设置功能，可重置界面、播放器、快捷键等偏好，保留曲库文件及播放统计。
- 本地文件夹右键菜单新增播放歌曲和加入歌单操作。
- 补充主题开发规范、变量默认值与作用范围、资源包清单及字体使用说明，并提供可导入示例。

## v3.2.1

- 新增可配置的快进与回退 5 秒、收藏歌曲、减少推荐和桌面歌词快捷键，支持应用内和全局绑定。
- 新增开启轻量模式的快捷键，默认使用 Ctrl+E，退出轻量模式仍需手动操作。
- 修复模式状态与实际窗口不同步时轻量模式快捷键失效的问题，并修复界面设置未正确保存到数据库的问题。
- 新增资料库单曲导入，支持选择本地音频文件加入资料库。
- 将文件夹导入入口统一命名为“导入文件夹”。
- 新增“忽略 5 秒以下的歌曲”开关，默认开启；文件夹和单曲导入均按此设置过滤短音频，并提示忽略数量。
- 将音频控制入口从底部栏移至顶部栏。
- 新增自动生成的构建号，可在设置中查看。
- 新增应用内更新日志，支持离线查看，并随界面语言显示中文或英文内容。
- 优化曲库搜索，支持拼音、罗马音与相关度排序，并改进中文、英文和日文混合名称排序。
