# 内置 Liquid Glass Studio 样式效果

在「设置 → 外观 → 主题背景」打开 **Liquid Glass 样式效果**。这是独立、持久化的开关，可叠加主题配色、自定义图片和视频；开关不会改动背景选择、媒体路径或明暗模式。默认关闭。此前的「流光玻璃」独立主题及其历次 `.epp` 安装包完整保留。

Header、侧栏、底栏、弹窗、抽屉、菜单、Popover、下拉选项沿用独立插件的实时 backdrop 合成：实际页面背景与下层内容 → 折射和 4% 轻染色的玻璃 → 透明边缘光 → 清晰控件。玻璃中心透出真实页面，弹窗遮罩继续影响其下方内容，不在面板中重复绘制不透明的主题底图。低模糊、固定光照，正常面板不监听鼠标。

光学参数最初参考 [Liquid Glass Studio 在线示例](https://liquid-glass.iyinchao.cn/) 的预设，定义在 `services/liquidGlassProfile.ts`。当前工作区的厚度、折射率、色散、模糊和高光参数保持原样，运行值以该文件为准。面板尺寸、圆角和单形状布局跟随实际 UI，不启用额外的鼠标圆形。Header、Footer 和侧栏仍保留清晰透底；弹窗、抽屉、菜单、Popover、下拉浮层使用当前模糊预设。原独立 `.epp` 主题参数保持原样。

内置 SVG 折射使用演示的 `asin((1-depth/thickness)^2)` 入射曲线及 Snell 定律。真实页面按 RGB 三个波长采样位移并重组，因此列表、文字和自定义背景下方的明暗交界都会呈现色散，而非只在主题环境纹理上生效。三个通道共用一张法线图和一次高斯模糊，不重复模糊或增加 WebGL 通道。平坦中心三个波长采样位置一致，保持高透；纯色背景的色散自然较弱。

WebGL 继续负责菲涅尔和边缘高光，其色散设为零以避免对已经分色的实际页面重复处理；光学预设中的色散值直接传入实时 SVG 波长偏移。着色器仍保留中性基线的透明合成能力。

上游的 `blurRadius` 是渲染像素采样半径，`sigma = radius / 3`。共享预设位于 `services/liquidGlassProfile.ts`。实时 SVG 换算为 `stdDeviation = radius / (3 × devicePixelRatio)`，浮层通过 `--ep-studio-blur-radius` 使用当前预设；模糊不作用于当前面板的文字和控件。WebGL 保留同一高斯核，将显示像素采样先等价映射到实际帧缓冲网格，再通过加权双线性采样合并相邻项。半径 60 时，每方向纹理读取由 121 次降为普通 DPI 的 61 次，2× DPI 且帧缓冲 DPR 1.25 时约 39 次；权重按面板尺寸及 DPR 缓存。数值验证覆盖不同缩放、边界钳制和亮度守恒。原始上游着色器文件保持不变，采样循环仅由宿主在编译时适配。

Header 的装饰 Canvas 显式使用 `-webkit-app-region: drag`，不再通过铺满 Header 的 `no-drag` 图层挖掉原生拖拽区域；画布仍不拦截页面指针，标题栏按钮和输入框保留各自的 `no-drag` 标记。

Footer 收起/展开时，材质背景、定位和 SVG 实时滤镜通过独立的 data 属性绑定，不依赖 Vue 会整体覆盖的 class 属性。切换首帧与整个过渡期间持续保持玻璃样式，无需等待下一帧恢复；装饰 Canvas 被内容更新移除时会重新挂回原面板。同尺寸类名更新不重绘 GPU。回归测试覆盖首帧即时样式、真实宽度过渡的逐帧透底像素、反复切换、同尺寸更新和关闭后的属性清理。

原插件的组件细节也随内置开关生效：胶囊按钮与柔和内高光、10px 输入/下拉圆角及输入底色、22px 弹窗/底栏圆角、20px 侧栏圆角、16px 菜单/Popover/选项浮层圆角、侧栏与菜单选中反馈、进度条和滚动条材质。侧栏染色 4%、底栏 6%、弹窗/抽屉 8%、浮层 12%，遮罩保持 18% 压暗。组件颜色由当前主题的背景、文字和强调色派生，保留原有主按钮/危险按钮配色、焦点、错误和禁用语义；关闭开关恢复所选主题样式。

边缘光直接使用 [iyinchao/liquid-glass-studio](https://github.com/iyinchao/liquid-glass-studio) 的 WebGL2 四通道渲染器和 GLSL：背景、双向高斯模糊、光学计算。适配器将最终输出转为预乘 alpha 的透明边缘增量，保留菲涅尔反射、色散和定向高光；实际页面折射和色散由 SVG backdrop 合成器承担，共享一张法线图。内置效果拥有独立实例，不与导入主题共享开关或资源生命周期。面板外阴影继续由 CSS 合成。

上游当前 `package.json` 标记为 `private: true`，其 pnpm 安装命令用于运行演示项目，并非发布的官方组件包。本实现直接内置 MIT 源码，不安装其他同名 React/原生库，也不包含上游演示媒体。固定提交 `f7b28c36305a862f5cffed3ddd51511cf1204f56`，原文件及 SHA-256 位于 `src/renderer/src/vendor/liquid-glass-studio/upstream.json`。适配器展开 GLSL include、映射背景坐标、提供面板参数并适配最终透明合成；原始光学计算保持不变。许可证随应用资源分发。

WebGL 边缘光的环境纹理跟随当前背景：宿主声明的常见线性/径向渐变、自定义图片和视频，以及 Canvas 背景。受信任官方主题通过宿主提供的脚本、私有 MessageChannel 返回限制为 1280×900 的背景 Canvas 位图；iframe 仍保持 `sandbox="allow-scripts"`，没有同源权限。只传背景像素，不读取父页面或业务控件。CSS 动画、伪元素及不能复制的 GPU/跨域内容使用主题声明的背景作为边缘光纹理；玻璃透底和实际下层内容继续由 Chromium 实时合成，不受这项纹理采样限制。

静态背景没有持续绘制循环，滚动与输入不重新生成环境纹理或几何图。内置模式在滚轮、滚动、输入和鼠标测试中持续使用同一套实时 RGB 折射，不切换轻量滤镜，也不等待停止后 180ms 再恢复。光学滤镜不参与 Footer 的 CSS 过渡；布局、显隐与颜色过渡保留。原独立插件仍保留其原有自适应交互策略。

边缘模糊开启后，三个波长共享一次高斯模糊，随后分别进行位移与颜色重组；只上传法线图，不生成未使用的反射和中心遮罩图。WebGL 对最终透明贡献为零的中心像素提前返回。滚动时持续使用相同滤镜，既不重建法线图，也不引入停止后的延迟恢复。

启动和尺寸更新时先解码法线 PNG，再启用对应的 SVG 滤镜；新图准备期间保留上一个可用滤镜。WebGL 画布保持隐藏，直到首张背景纹理上传并完整绘制后才显示，避免默认位移或空画布带来的 Footer 黑边闪烁。资源未就绪时保留透明 CSS 回退，关闭期间未完成的异步提交不会重新挂回材质。

只有面板位置/大小、背景或主题变化时重绘 WebGL。播放器本身的 loadeddata/play/pause/seeked 不再触发环境采样，仅背景层媒体触发更新。动态背景纹理尺寸不变时使用 texSubImage2D 复用显存，仅首次或尺寸变化时分配；测试校验分配和更新次数。动画环境纹理最多 10fps，尺寸上限 1280×900；这个限频只影响背景环境光，不限制 Chromium 对页面滚动的实时折射。最多 8 个 WebGL 面板、单面板渲染像素预算 450000、DPR 上限 1.25。关闭开关释放 GL 上下文、帧缓冲、纹理、SVG 滤镜、消息端口、观察器和计时器，并恢复面板原有背景样式。隐藏窗口与失焦设置、减少动态效果、播放器遮挡均参与调度；原生窗口材质和极致播放模式暂停此效果。无 WebGL2/浮点颜色缓冲支持时保留透明 CSS 面板，控件继续可用。

内置模式启用时暂停独立主题的 SVG glass 渲染器，防止两套折射叠加；关闭后恢复主题原有玻璃效果。主题的配色、字体和其他规则仍然有效。

验证命令：`npm run test:liquid-glass-studio`；`EP_GLASS_DPR=2` 验证高 DPI；`EP_GLASS_NO_WEBGL=1` 验证 GPU 不可用。测试包含原始文件哈希、真实 WebGL 四通道绘制、背景切换、图片/视频、隔离 iframe 位图、页面/遮罩透底、静态交互零重绘，真实 DOM 灰度背景色散、延迟解码下的启动/尺寸切换逐帧边缘、以及资源清理。预览和帧耗时报告输出到 `build/themes/liquid-glass-studio/`。已有独立主题继续使用 `npm run test:liquid-glass` 验证。

`npm run test:liquid-glass-components` 使用真实 Vue 按钮、输入框、下拉、菜单、Popover、弹窗和抽屉，分别验证深色/浅色主题的几何、透明度、状态语义、交互、Teleport 浮层继承和停用后的完整样式恢复；输出 `components-dark.png`、`components-light.png` 和 `components.json`。

`npm run test:liquid-glass-scroll` 发送真实普通鼠标滚轮输入，逐帧对比 Footer 透底与同一水平线未遮挡区域的滚动像素，并检查滚动前、滚动中、停止后的滤镜身份一致、实时 RGB 位移持续有效、没有延后恢复定时器或光学滤镜过渡。输出 `scroll-verification-1x.json`；可用 `EP_GLASS_DPR=2` 检查高 DPI。

组件覆盖补充到颜色选择器、消息通知、开关、滑块、原生进度条和骨架屏。颜色/消息浮层及主动标记 `.ep-glass-panel` 的独立面板参与完整折射，仍遵守 8 个 WebGL 表面的预算；其他小控件采用静态 CSS 玻璃高光、边框和阴影，不创建独立 GL 上下文。主/危险按钮、选色渐变、消息图标/状态条、focus/invalid/disabled 等语义保持原样。

uiDEV `/dev/ui` 顶部加入真实组件的玻璃阅览场景：全局开关与外观设置同步，支持浮层、颜色、消息和弹窗叠加，展示状态与交互；可临时预览模糊/圆角/染色并查看可合并到插件 JSON 的片段。恢复或 KeepAlive 离开时还原之前的变量值和优先级，只清理该预览创建的消息。

主题插件可通过 23 个 `--ep-glass-*` 变量修改组件几何、颜色、染色、模糊、边框、高光和阴影。SDK 的 `THEME_GLASS_TOKENS` 与 `PluginThemeTokens`、JSON Schema 和 uiDEV 的属性清单共用目录；变量参考见 [theme-variables.md](theme-variables.md#liquid-glass-组件参数)。浮层模糊令牌同时影响实时 SVG 和 WebGL 采样，支持半径 0–200，继续使用等价合并后的高斯核。验证命令 `npm run test:liquid-glass-components` 覆盖深浅主题、禁用/键盘/选色交互、Teleport、真实光学浮层、临时变量恢复和无额外小控件上下文；新增 `gallery.png` 与 `gallery.json` 输出。

Input 补齐高透玻璃高光和阴影，缺省底色比例 8%，自身不再叠加 backdrop 模糊。抽屉和浮层的过渡属性包含 Tailwind 的 translate/scale/rotate 长属性，同时继续排除 backdrop-filter，避免折射跟随滚动延迟。Select 玻璃边框与原生滚动列表分离，覆盖式滚动条支持拖拽，内层滚动不触发整层重新定位；uiDEV 长选项列表可验证滚动后边缘和位置稳定。

歌曲列表的回到顶部按钮已抽为 `BaseBackTop`，保留 320px 显示阈值、虚拟列表回顶和 Footer 避让，普通窗口和容器也可独立复用。`.ep-backtop` 加入统一玻璃引擎并使用清透、零额外模糊的材质；隐藏时销毁表面，不启动独立动画循环。uiDEV 新增滚动演示，四个 `--ep-backtop-*` 几何变量由 SDK/Schema 提供补全，详情见 [主题变量参考](theme-variables.md#backtop-独立组件)。

Tooltip 已整理为 `BaseTooltip`，使用 `.ep-tooltip` 独立样式。Footer 音量及播放页音量、倍速、歌词偏移、字号、行距的悬浮调节器共享同一材质与生命周期；仅提示打开时挂载有预算限制的玻璃面。调节面板 Teleport 至 body，保留 hover 移入、滚轮、拖动和键盘操作，普通主题通过同一组 Tooltip 变量调整外观。uiDEV 补充文字/音量/倍速演示。

已移除设置中的鼠标跟随玻璃测试框及其运行状态、组件和文案。uiDEV 的组件效果阅览继续用于展示实际 UI 材质。

Footer「更多」菜单使用独立的 `.ep-footer-more-menu` 浮层，Teleport 至 body，避免在 Footer 自身的 backdrop 根内采样而使菜单外伸区域的模糊失效。开启 Liquid Glass 时沿用菜单的染色和 `--ep-glass-floating-blur-radius` 模糊预设；页面文字和菜单控件保持清晰。菜单保留滚动、自动定位、折叠/窄布局补充项和 Footer 自动隐藏联动。

Footer 收起与展开统一为 84px 高度，宽度与布局继续按原过渡切换。更多菜单以 Footer 上沿为垂直基准、稳定的按钮外层为水平基准，与 Footer 保持 6px 间距；高度由菜单内容自然撑开，上限为 480px、视口高度的 70% 和实际可用空间三者的较小值，内容超出时内部滚动。`.ep-footer-more-menu` 只承担玻璃外框，`.ep-footer-more-list` 负责内部滚动并保留稳定滚动条间距。菜单滚动不会改变外框大小或重新定位，兄弟页面区域的滚动也不触发浮层重算；实际祖先滚动和窗口尺寸变化仍能正确更新一般浮层的位置。

播放页工具按钮保持独立的浅色前景，不随主界面明暗或 Tooltip 文字变量改变。SVG 法线预算在新图解码期间仍计入保留的旧图；预算不足时释放旧滤镜，缩小后的图提交后自动把腾出的空间用于其他面板。官方动态背景即使首次返回空帧或快照超时，也保持有上限的采样重试，暂停和减少动态效果仍由原调度器控制。`npm run test:liquid-glass-regressions` 覆盖按钮对比度、预算耗尽/恢复、空帧/超时恢复及暂停后的停止重试。
