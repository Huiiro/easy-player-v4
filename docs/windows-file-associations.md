# Windows 文件关联

安装程序为 MP3、AAC、M4A、OGG、OPUS、FLAC、WAV、AIFF、APE、DFF、DSF 注册
Easy Player 的“打开方式”候选项及默认应用能力。注册范围随安装程序的当前用户 / 所有用户
选项决定，卸载时清理相同范围内的注册项。

## 使用

安装新版本后，打开 **设置 → 系统 → 文件关联 → 设置文件关联**，在 Windows 默认应用中
选择 Easy Player 并确认需要关联的扩展名。也可以右键音频文件，在“打开方式”中选择
Easy Player。开发模式不会向注册表注册 Electron。

双击关联文件会启动播放器并播放该文件；播放器已运行时，文件交给现有实例。
文件尚未入库时，仅导入指定文件并读取元数据，已有歌曲复用现有记录。
打开的文件插入当前歌曲后，从第一个打开的文件开始播放，保留原队列和播放模式。
文件已经在队列中时直接播放已有项，不重复添加。冷启动时先恢复原队列，再插入文件。

## 验证

自动检查：`node scripts/check-file-associations.cjs`。

安装后的人工检查：

1. 运行 `npm run build:win`，安装生成的安装程序。
2. 在音频文件的“打开方式”和 Windows 默认应用中确认可以选择 Easy Player。
3. 退出播放器后，双击包含中文和空格路径的音频文件，确认正确播放。
4. 播放器运行或隐藏到托盘时，打开另一个音频文件，确认原窗口显示且播放新文件。
5. 在系统设置中点击“设置文件关联”，确认跳转到 Windows 默认应用页面。
6. 卸载后确认 Easy Player 的打开方式注册项已清理。

安装程序注册候选应用，不修改 Windows 的 UserChoice；最终默认关联通过 Windows 界面确认。

文件类型按格式显示，例如“MP3 音频”“FLAC 音频”（英文安装显示 MP3 Audio、FLAC Audio）。
从旧版升级时，已有的共用类型关联继续有效并显示“音频文件”。要使用新的格式名称，
需要在 Windows 默认应用中重新选择一次对应格式的 Easy Player；升级不会强制修改默认关联。
